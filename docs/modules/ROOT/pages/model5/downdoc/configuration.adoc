= Converting to Markdown with {downdoc-name}

With the 5.0 release, there is now the ability to convert Asciidoc to Markdown using the {downdoc-url}[{downdoc-name}] tool.
This toolchain does not use any of the Asciidoctor engines underneath, but it provides its own `pnpm`-based toolchain.
It is available via the `org.asciidoctor.downdoc` plugin.


[tabs]
====
Groovy::
+
--
[source,groovy,subs=+attributes]
----
plugins {
    id 'org.asciidoctor.downdoc' version '{release-version}'
}

asciidoc {
    toolchains {
        downdoc {

        }
    }

  publications {
    main {

        output 'downdoc', 'markdown' // <.>
    }

  }
}
----
<.> The default toolchain is called `downdoc` and the default formatter is `markdown`.

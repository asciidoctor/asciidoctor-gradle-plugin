= Quick Start

To start you need to use one of the plugins from the following Gradle snippet

[tabs]
====
Groovy::
+
--
[source,groovy]
[subs=attributes+]
.build.gradle
----
plugins {
    id 'org.asciidoctor.jvm.convert.classic' version '{release-version}'
}
----
--

Kotlin::
+
--
[source,kotlin]
[subs=attributes+]
.build.gradle.kts
----
plugins {
    id("org.asciidoctor.jvm.convert.classic") version "{release-version}"
}
----
--
====

= Known Issues

These are the main ones we know about:

* Full compatibility on Windows has not been established.
  This is especially relevant to the `asciidoctor.js` toolchain on the new model and also on the class plugins.
  Please raise any Windows issues that you might encounter, but PRs would be even better.
* JRuby 10 needs Java 21 or later.
  {asciidoctorj-name} 3.0.1 uses JRuby 9.4.14.0, see xref:model5/asciidoctorj/jruby-and-daemon-memory.adoc[] for how to use JRuby 10.
  Some {asciidoctorj-name} extensions had problems with JRuby 10, see https://github.com/asciidoctor/asciidoctorj/issues/1299[asciidoctorj#1299].
* With older Gradle or JRuby versions, and with version 5.1.0 of this plugin, conversions that run in the Gradle daemon need a metaspace limit, see xref:model5/asciidoctorj/jruby-and-daemon-memory.adoc#daemon-memory[Memory use in the Gradle daemon].
* Multi-languages are not (yet) supported on the new model.
* Groovy DSL is not (yet) supported on the new model.

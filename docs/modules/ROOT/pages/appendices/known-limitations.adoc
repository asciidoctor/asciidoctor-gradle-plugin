= Known Issues

These are the main ones we know about:

* Full compatibility on Windows has not been established.
  This is especially relevant to the `asciidoctor.js` toolchain on the new model and also on the class plugins.
  Please raise any Windows issues that you might encounter, but PRs would be even better.
* JRuby 10 compatibility has not been tested.
  It is possible that it might work when runnign JDK21, but see https://github.com/asciidoctor/asciidoctorj/issues/1299[asciidoctorj#1299].
* Multi-languages are not (yet) supported on the new model.
* Groovy DSL is not (yet) supported on the new model.
